# ADR-002: Room como fonte local de verdade, com carga inicial a partir de assets (offline-first)

| Item | Registro |
|---|---|
| Status / Data | ☑ Aceita · 11/11/2026 |
| Contexto | O app precisa funcionar sem internet, guardar séries temporais, alertas e decisões humanas (rastreabilidade) e mostrar a data da última atualização. O escopo da disciplina não inclui servidor. |
| Decisão | Decidimos usar **Room** para leituras, alertas, decisões e registro de notificações, **DataStore** para preferências e **CSV em assets** como carga inicial versionada por `seed_version.txt`. O domínio só conhece interfaces de repositório. |
| Alternativas consideradas | **API remota**: exige servidor, rede e autenticação; fora do escopo e quebra o uso offline. **Arquivos JSON/CSV lidos a cada abertura**: sem consultas, sem decisões persistidas, lento em séries horárias. **SharedPreferences para tudo**: não serve para séries nem relacionamentos. |
| Consequências positivas | Funciona offline; consultas indexadas; decisões sobrevivem a reinício; trocar a fonte (assets por API) mexe só em `data`. |
| Consequências negativas | Dados envelhecem (validade de 7 dias, com aviso e modo demonstração); recarga do seed ao mudar a versão; sem sincronização entre aparelhos. |

**Política de atualização:** nova carga a cada versão dos dados; o app mostra "atualizado há X" e bloqueia alertas com dados vencidos.
